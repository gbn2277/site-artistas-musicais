# Site Artistas Musicais

Site colaborativo desenvolvido pela equipe do Instituto JEF, 1º G Tech, como projeto prático de Git e GitHub. O site apresenta a biografia, carreira e discografia de quatro artistas musicais icônicos.

## Equipe

 Aluno(a)  |           Página              | Artista 

 Daniel   - `paginas/aluno-daniel.html`   -  The Beatles 
 Gabriela - `paginas/aluno-gabriela.html` -  SZA 
 Miguel   - `paginas/aluno-miguel.html`   -  Luan Santana 
 Matheus  - `paginas/aluno-matheus.html`  -  Michael Jackson 

## Sobre as páginas

**index.html** - Página inicial do site, com um resumo de cada artista e links para as páginas individuais.

**The Beatles** - Formação, início de carreira, Beatlemania, evolução musical, curiosidades e principais álbuns (com links para o Spotify).

**SZA** - Biografia, carreira, discografia, músicas de maior sucesso, prêmios e curiosidades.

**Luan Santana** - Infância, início da carreira, explosão nacional, trajetória como astro, vida pessoal e músicas mais ouvidas.

**Michael Jackson** - Biografia completa, galeria de álbuns e músicas favoritas.


## Como abrir o site

1. Acesse o link do site publicado: `https://github.com/gbn2277/site-artistas-musicais.git`

Ou, para rodar localmente:
1. Clone o repositório: `git clone https://github.com/gbn2277/site-artistas-musicais.git`
2. Abra o arquivo `index.html` no navegador
